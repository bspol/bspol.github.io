현재 GitHub Pages 사이트 bspol.github.io 의 기존 사이트를 수정한다. 이번 작업의 목적은 기존 4개국어 사이트를 7개국어 사이트로 확장하는 것이다. 절대로 처음부터 새 사이트를 만들지 말고, 현재 index.html의 기존 구조와 작동 방식을 유지하면서 필요한 부분만 수정한다. ================================================== [1. 가장 중요한 작업 원칙] ================================================== 기존 사이트의 기능과 구조를 최대한 보존한다. 절대로 다음을 하지 않는다. - 기존 index.html을 처음부터 새로 작성하지 않는다. - 기존 파일을 삭제하지 않는다. - 기존 파일명을 임의로 변경하지 않는다. - 기존 URL을 변경하지 않는다. - 기존 QR 코드 연결 주소를 변경하지 않는다. - 기존 4개국어 페이지를 삭제하지 않는다. - 기존 외부 링크를 임의로 변경하지 않는다. - 기존 이미지의 디자인을 CSS로 다시 제작하지 않는다. - 새로운 프레임워크를 사용하지 않는다. 현재 사이트는 하나의 index.html에서 PNG 이미지들을 화면별로 표시하고 이미지 위에 투명한 터치 영역을 배치하여 페이지를 전환하는 구조이다. 이 기존 방식을 그대로 유지한다. ================================================== [2. 메인 이미지] ================================================== 기존 home.png 파일은 이미 새로운 7개국어 메인 이미지로 교체되어 있다. 현재 repository에 있는 home.png을 그대로 사용한다. 새로운 home.png은 1080x1920 비율의 이미지이며 다음 7개 언어 버튼이 이미지 안에 표시되어 있다. 1. ENGLISH 2. 日本語 3. 中文 4. TIẾNG VIỆT 5. МОНГОЛ 6. FILIPINO 7. РУССКИЙ 중요: 이미지 안의 글자와 버튼 디자인은 수정하지 않는다. HTML/CSS로 새로운 버튼을 보이게 만들지 않는다. 이미지 위에 투명한 클릭/터치 영역만 배치한다. ================================================== [3. 새로운 home.png의 7개 언어 버튼 위치] ================================================== home.png의 실제 이미지 비율을 기준으로 아래 위치에 투명한 터치 영역을 배치한다. 1행: ENGLISH top 약 58.2% left 약 7.5% width 약 19% height 약 10% 日本語 top 약 58.2% left 약 29.5% width 약 18% height 약 10% 中文 top 약 58.2% left 약 51.5% width 약 18% height 약 10% TIẾNG VIỆT top 약 58.2% left 약 73.5% width 약 19% height 약 10% 2행: МОНГОЛ top 약 69.5% left 약 12% width 약 22% height 약 10% FILIPINO top 약 69.5% left 약 37.5% width 약 23% height 약 10% РУССКИЙ top 약 69.5% left 약 64% width 약 23% height 약 10% 위 값은 투명 터치 영역의 기준값이다. 이미지의 실제 버튼과 최대한 정확하게 일치하도록 조정한다. 버튼 사이의 빈 공간이 다른 언어 버튼으로 잘못 인식되지 않도록 한다. ================================================== [4. 최종 언어] ================================================== 최종적으로 총 7개 언어를 지원한다. English Japanese Chinese Vietnamese Mongolian Filipino Russian 기존 4개 언어는 반드시 그대로 유지한다. 기존: en cn jp vn 추가: mn ph ru 단, repository에 이미 몽골어/필리핀어/러시아어 파일이 존재한다면 반드시 실제 파일명을 먼저 확인하고 그 파일명을 그대로 사용한다. 파일이 있는데도 임의로 새로운 파일명을 만들지 않는다. ================================================== [5. 기존 언어 이미지] ================================================== 현재 기존 코드에는 다음 언어 이미지가 있다. main_en.png main_cn.png main_jp.png main_vn.png 이 4개는 그대로 유지한다. 기존 하위 페이지도 그대로 유지한다. hospital_en.png hospital_cn.png hospital_jp.png hospital_vn.png medical-info-en.png medical-info-cn.png medical-info-jp.png medical-info-vn.png pharmacy_en.png pharmacy_cn.png pharmacy_jp.png pharmacy_vn.png 기존 파일을 삭제하지 않는다. ================================================== [6. 새로운 3개 언어 페이지] ================================================== repository를 먼저 확인하여 몽골어 필리핀어 러시아어 페이지에 해당하는 실제 PNG 파일이 있는지 확인한다. 있다면 해당 파일을 연결한다. 예를 들어 실제 파일명이 main_mn.png main_ph.png main_ru.png 이라면 각각 연결한다. 하지만 실제 repository의 파일명이 다르면 실제 파일명을 사용한다. 없는 파일을 임의로 생성하지 않는다. ================================================== [7. goPage() 함수 수정] ================================================== 현재 goPage() 함수는 en / cn / jp / vn만 언어로 인식하고 있다. 이를 7개 언어로 확장한다. 언어 ID: en cn jp vn mn ph ru currentLang도 7개 언어를 모두 정상적으로 저장해야 한다. 기존: var currentLang = 'en'; 구조를 유지한다. 페이지 이동 방식도 기존 goPage() 방식을 그대로 유지한다. ================================================== [8. 메인 화면의 7개 언어 버튼] ================================================== 기존의 area-en area-cn area-jp area-vn 구조를 유지하면서 area-mn area-ph area-ru 를 추가한다. 각 버튼은 투명한 터치 영역으로 만든다. 예: onclick="goPage('mn')" onclick="goPage('ph')" onclick="goPage('ru')" 방식으로 연결한다. ================================================== [9. 언어 페이지의 공통 메뉴] ================================================== 각 언어 메인 페이지에서 기존과 동일하게 112 119 1330 전화 버튼이 작동해야 한다. 그리고 기존 메뉴인 Hospital Pharmacy Embassy Lost & Found Law & Order / Basic Rules Busan Tourist Spots 도 작동해야 한다. 새로운 3개 언어에서도 동일하게 작동해야 한다. ================================================== [10. 언어 드롭다운] ================================================== 기존 언어 드롭다운 기능을 유지한다. 현재 드롭다운은 Home English Chinese Japanese Vietnamese 구조이다. 이를 7개 언어로 확장한다. 최종: 🏠 메인 (Home) 🇬🇧 English 🇯🇵 日本語 🇨🇳 中文 🇻🇳 Tiếng Việt 🇲🇳 Монгол 🇵🇭 Filipino 🇷🇺 Русский 각 항목을 누르면 해당 언어 메인 화면으로 이동한다. ================================================== [11. 기존 메뉴 기능 유지] ================================================== 기존 언어 메인 화면의 6개 메뉴 기능을 그대로 유지한다. 1. Hospital 2. Pharmacy 3. Embassy 4. Lost & Found 5. Law & Order / Basic Rules 6. Busan Tourist Spots 기존 코드에는 다음과 같은 방식으로 현재 언어에 따라 Hospital / Pharmacy 페이지를 연결하는 구조가 있다. sub-hospital-' + currentLang sub-pharmacy-' + currentLang 이 구조를 유지하고 새로운 mn / ph / ru 언어에서도 작동하도록 확장한다. ================================================== [12. 병원 / 약국 / 의료정보] ================================================== 기존 4개 언어의 Hospital Pharmacy Medical Information 기능을 절대로 깨뜨리지 않는다. 새로운 3개 언어용 이미지가 repository에 존재한다면 동일한 구조로 연결한다. 각 언어의 병원/약국/의료정보 페이지에서도 현재 언어가 유지되어야 한다. 예: mn → 몽골어 하위 페이지 ph → 필리핀어 하위 페이지 ru → 러시아어 하위 페이지 ================================================== [13. LAW & ORDER / BASIC RULES] ================================================== 현재 사이트에 이미 basicrules.png 가 존재한다. 이 파일과 기존 Basic Rules 연결 구조를 삭제하지 않는다. 새로운 법과 질서 페이지 이미지가 별도로 repository에 존재한다면 실제 파일명을 확인하여 연결한다. 페이지 하단의 112 119 1330 전화 버튼도 기존처럼 작동해야 한다. 현재 코드에는 Basic Rules 페이지의 rules-call-112 rules-call-119 rules-call-1330 터치 영역이 존재하므로 이 기능을 유지한다. ================================================== [14. Embassy] ================================================== 현재 embassy.png 페이지와 각 국가별 전화/홈페이지 버튼 구조를 유지한다. 기존 11개 국가의 대사관 연결을 삭제하거나 임의 변경하지 않는다. 기존 외부 URL도 그대로 유지한다. ================================================== [15. Lost & Found] ================================================== 기존 분실물 링크를 그대로 유지한다. 현재 연결된 경찰민원24 링크를 임의 변경하지 않는다. ================================================== [16. Tourist Map] ================================================== 기존 부산 관광지도 링크를 그대로 유지한다. ================================================== [17. 전화번호] ================================================== 모든 언어 페이지에서 112 → tel:112 119 → tel:119 1330 → tel:1330 이 정상 작동해야 한다. 기존 전화 버튼의 위치와 기능을 유지한다. ================================================== [18. 기존 QR 코드 보호] ================================================== 매우 중요하다. 현재 이미 배포되어 있는 QR 코드는 bspol.github.io의 기존 주소로 연결된다. 이번 작업으로 기존 QR 코드가 절대로 깨지면 안 된다. 따라서 - GitHub Pages 주소 변경 금지 - repository 구조의 불필요한 변경 금지 - 기존 index.html의 진입 경로 유지 - 기존 URL 유지 - 기존 QR 재발급 불필요 를 원칙으로 한다. 기존 QR을 찍으면 새로운 7개국어 home.png 화면이 바로 표시되어야 한다. ================================================== [19. 모바일 화면] ================================================== 스마트폰 사용을 기준으로 한다. 1080x1920 이미지 비율을 유지한다. 기존의 width: 100%; height: auto; 방식을 유지한다. 이미지를 강제로 crop하거나 높이를 변경하지 않는다. 가로 스크롤이 발생하지 않도록 한다. 터치 영역이 이미지 위치와 정확하게 일치해야 한다. 특히 iPhone과 Android에서 7개 언어 버튼을 정확하게 누를 수 있어야 한다. ================================================== [20. 기존 코드의 CSS 구조 유지] ================================================== 현재 사이트에는 .main-img .active .touch-link 등의 구조가 있다. 이 구조를 그대로 사용한다. 기존 이미지 전환 방식도 그대로 사용한다. 필요한 경우 새로운 언어 버튼용 CSS만 추가한다. 기존 버튼의 CSS를 불필요하게 수정하지 않는다. ================================================== [21. 작업 전 반드시 확인] ================================================== 작업하기 전에 repository의 실제 파일 목록을 확인한다. 특히 다음을 확인한다. - home.png - main_en.png - main_cn.png - main_jp.png - main_vn.png - 몽골어 관련 파일 - 필리핀어 관련 파일 - 러시아어 관련 파일 - hospital 관련 파일 - pharmacy 관련 파일 - medical information 관련 파일 - basicrules 관련 파일 - embassy 관련 파일 - index.html 실제 존재하는 파일명을 기준으로 작업한다. ================================================== [22. 절대로 기존 4개국어를 망가뜨리지 말 것] ================================================== 작업 후 반드시 확인한다. English → 정상 Chinese → 정상 Japanese → 정상 Vietnamese → 정상 기존 4개 언어가 기존과 동일하게 작동해야 한다. 그 위에 Mongolian Filipino Russian 3개 언어를 추가한다. ================================================== [23. 최종 테스트] ================================================== 작업 완료 후 다음을 모두 확인한다. □ home.png 정상 표시 □ English 버튼 정확한 위치에서 클릭 □ Japanese 버튼 정확한 위치에서 클릭 □ Chinese 버튼 정확한 위치에서 클릭 □ Vietnamese 버튼 정확한 위치에서 클릭 □ Mongolian 버튼 정확한 위치에서 클릭 □ Filipino 버튼 정확한 위치에서 클릭 □ Russian 버튼 정확한 위치에서 클릭 □ 언어 드롭다운 7개 언어 표시 □ 드롭다운에서 각 언어 이동 가능 □ 112 작동 □ 119 작동 □ 1330 작동 □ Hospital 작동 □ Pharmacy 작동 □ Embassy 작동 □ Lost & Found 작동 □ Law & Order / Basic Rules 작동 □ Tourist Map 작동 □ 기존 English 하위 페이지 작동 □ 기존 Chinese 하위 페이지 작동 □ 기존 Japanese 하위 페이지 작동 □ 기존 Vietnamese 하위 페이지 작동 □ 새 Mongolian 하위 페이지 작동 □ 새 Filipino 하위 페이지 작동 □ 새 Russian 하위 페이지 작동 □ 기존 외부 링크 유지 □ 기존 QR 주소 유지 □ GitHub Pages 주소 유지 □ 모바일 화면 정상 □ 이미지 비율 유지 □ 가로 스크롤 없음 □ 기존 기능 삭제 없음 ================================================== [24. 작업 완료 보고] ================================================== 작업이 끝나면 다음만 간단하게 알려준다. 1. 수정한 파일 2. 추가한 파일 3. 기존 파일 중 삭제/이름 변경 여부 4. 7개 언어 연결 상태 5. 기존 QR 주소 유지 여부 기존 파일을 삭제하거나 이름을 변경했다면 반드시 그 이유를 설명한다. 가장 중요한 것은 "새 사이트 제작"이 아니라 "기존 4개국어 사이트를 안전하게 7개국어로 확장"하는 것이다.
